## Quick Setup & Execution

```bash
cd xv6-public
make qemu-nox
```

To exit QEMU at any point: press `Ctrl-A` then `X`.

---

## Interactive Demo Flow

### 1. Initial Boot Event Stream
**Command:**
```bash
$ ulog_tool
```
**Output:**
```
Kernel Event Stream (3 records retrieved):
------------------------------------------------------------
[0] INFO  Core0 PID0: klog: kernel event logging subsystem initialized (v2.0)
[1] INFO  Core0 PID1: exec: sh
[2] INFO  Core0 PID1: fork: pid 1 created child 2
```

---

### 2. Multi-Level Severity Filtering (Novel Feature)
View only warnings and errors without being overwhelmed by routine file access:
**Command:**
```bash
$ cat non_existent_file
$ ulog_tool -l WARN
```
**Output:**
```
Kernel Event Stream (1 records retrieved):
------------------------------------------------------------
[14] WARN  Core0 PID3: open: file not found non_existent_file
```

---

### 3. Process ID (PID) Scoped Tracing (Novel Feature)
Filter logs specifically generated by a single targeted process:
**Command:**
```bash
$ ulog_tool -p 2
```
**Output:**
```
Kernel Event Stream (8 records retrieved):
------------------------------------------------------------
[3] INFO  Core0 PID2: exec: ls
[4] INFO  Core0 PID2: open: . fd=3
[5] INFO  Core0 PID2: exit: pid 2 exiting
```

---

### 4. Interactive User-to-Kernel Logging via `/dev/klog` (Novel Feature)
Direct user-space event injection into the kernel ring buffer (similar to Linux `/dev/kmsg`):
**Command:**
```bash
$ echo "Application checkpoint Alpha reached" > klog
$ ulog_tool -n 3
```
**Output:**
```
Kernel Event Stream (3 records retrieved):
------------------------------------------------------------
[22] INFO  Core0 PID4: user[4]: Application checkpoint Alpha reached
```

---

### 5. Kernel Subsystem Telemetry & Dropped Counter Inspection (Novel Feature)
Query hardware CPU statistics, sequence tickets, and ring buffer overflow metrics:
**Command:**
```bash
$ ulog_tool -s
```
**Output:**
```
===============================================
   xv6 Kernel Logging Subsystem Telemetry      
===============================================
  Total Log Sequence ID : 48
  Active CPU Cores      : 8
  Capacity Per Core     : 256 entries
  Dropped/Overwritten   : 0 entries
===============================================
```

---

### 6. Administrative Ring Buffer Flush (Novel Feature)
Flush and reset all per-core circular buffers using `klogctl`:
**Command:**
```bash
$ ulog_tool -c
$ ulog_tool
```
**Output:**
```
[+] Kernel log ring buffers cleared successfully.

Kernel Event Stream (1 records retrieved):
------------------------------------------------------------
[49] INFO  Core0 PID5: klog: ring buffers flushed by administrator
```
